## Endmember choices (splib06a, Beckman spectrometer, 0.2–3.0 µm)

| Endmember | Spectrum |
|-----------|----------|
| Jarosite | Jarosite GDS99 K 200C Syn (K-jarosite, purity grade a) |
| Goethite | Goethite WS222 Medium Gr. (a) |
| Ferrihydrite | Ferrihydrite GDS75 Syn F6 (b). This is the only ferrihydrite spectrum in splib06a. |
| Montmorillonite | Montmorillonite SWy-1 (b), the Clay Minerals Society reference smectite |
| Gypsum | Gypsum SU2202 (a) |
| Quartz-Feldspar | **Derived** 50/50 linear mix of Quartz GDS31 (a) and Orthoclase HS13.3B (c). splib06a has no single quartz–feldspar spectrum. |
| Water-Shade | Seawater_Open_Ocean SW2 (a), the dark water/shade background |

## splib07

The playbook asks for `usgs_splib07_extract.csv`. The USGS splib07 servers (crustal.usgs.gov, sciencebase.gov) were not reachable from the environment that built these files, so the splib06a extract is bundled instead. These samples are also in splib07a (the L2B grouping matrix links to their splib07 metadata pages), but the splib07a spectra may differ slightly from the splib06a ones.

To use splib07, place a `usgs_splib07_extract.csv` with the same columns in `DATA_DIR/reference/` or in this directory. `app/pipelines/unmixing.py` uses it in preference to the splib06a file.
